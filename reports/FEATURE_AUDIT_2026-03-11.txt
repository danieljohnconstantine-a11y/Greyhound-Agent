===============================================================================
v5.3 FIXES — 4 BUGS FOUND AND RESOLVED
===============================================================================

FIX #1: RecentPlaceStreak ALWAYS 1.0 (CRITICAL)
  Problem: Code checked for 'Last3Finishes' column which is NEVER generated by
           the PDF parser. Every dog got neutral 1.0. Useless feature.
  Fix:     Now derives from 'Margins' (available from parser). Margin ≥ -2.5
           lengths = competitive placing (2nd or 3rd). Returns 0.98-1.12 range.
  Impact:  Feature now differentiates dogs based on recent placing history.
           Retraining models will extract more signal from this feature.

FIX #2: CompetitorDensity fallback wrong (MEDIUM)
  Problem: When EarlySpeedIndex was constant (all dogs same std=0), the formula
           returned 0 (not the expected 0.5 fallback). The fallback 0.5 was
           only used when <2 non-NaN values. Zero was meaningless.
  Fix:     Now tries BestTimeSec spread as fallback when EarlySpeedIndex has no
           variance. Dogs above/below median BestTimeSec correctly classified.
  Impact:  CompetitorDensity and CompetitorAdjustment now meaningful for races
           where sectional timing is missing.

FIX #3: FieldSimilarityIndex overly pessimistic (LOW-MEDIUM)
  Problem: When FieldSpeedStd was low (e.g., 0.3), FieldSimilarityIndex defaulted
           to 1.1 (unpredictable) even if FieldTimeStd showed real time variance.
           A race where dogs have 0.8s time spread was wrongly marked "unpredictable".
  Fix:     Added FieldTimeStd ≥ 0.5s as secondary threshold for "normal" (1.0).
           Still returns 0.8 if either spread is very high (good separation).
  Impact:  More accurate confidence calibration. Fewer races wrongly penalized.

FIX #4: RTCFactor, TimeVsField, SpeedVsField, RecentFormBoost unused in FinalScore (MEDIUM)
  Problem: These 4 features were computed, stored, and fed to ML models, but
           were NOT included in get_weights() and NOT used in the heuristic
           FinalScore calculation. The FinalScore was missing important signals:
           - RTCFactor (grade/class indicator)
           - TimeVsField (dog faster/slower than race average)
           - SpeedVsField (dog's early speed vs race average)
           - RecentFormBoost (fresh + recent winner binary signal)
  Fix:     Added all 4 to get_weights() dictionaries for all 3 distance categories.
           Added RTCFactor + RecentFormBoost to career_score.
           Added TimeVsField (negated) + SpeedVsField to speed_score.
           Added RecentPlaceStreak as additive weight to form_score.
  Impact:  FinalScore now correctly incorporates all key features. Predictions
           should better rank dogs by class, relative speed, and recent form.
