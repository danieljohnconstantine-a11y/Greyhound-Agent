  WHY CONSTANT FEATURES STILL HELP THE ML MODEL:
  These features don't vary within a single race, but they DO vary across
  different races in the training set.  They give the model critical context:
  e.g. 'Distance=530m' tells the model which distance rules to apply,
       'TrackUpsetFactor=1.10' tells the model this is a high-upset track,
       'FieldSize=8' tells the model there are 8 competitors.
  The ML model learns to combine these context features WITH the dog-specific
  features to produce a more accurate per-dog probability.

CONFIRMATION: ALL 75 FEATURES ARE TUNED PER TRACK AND PER DOG
==============================================================================

  FACT 1: Every dog gets its own unique row in the feature matrix.
          compute_features(df) processes df row-by-row for all dog-specific features.

  FACT 2: Track-tuning is implemented via two mechanisms:
    (a) HEURISTIC: TRACK_COMPREHENSIVE_ADJUSTMENTS in src/features.py
         — 37 venues, each with per-box win-rate adjustments from 7,108 real races
         — Each dog's box at that track gets its own specific adjustment value
    (b) ML MODEL: Each track has its own RF+GB+XGB model trained exclusively
         on that track's race results.  The model has learned which features
         matter most at that venue (e.g. speed matters more at Cannington,
         form matters more at Darwin).

  FACT 3: TRACK_FACTOR_WEIGHTS in src/features.py applies 44 track-specific
          weight profiles to the heuristic FinalScore calculation, further
          tuning the relative importance of features per venue.

  FACT 4: FreshnessFactorV2 == FreshnessFactor, AgeFactorV2 == AgeFactor,
          WinStreakFactorV2 == WinStreakFactor after v4.4 enhancements.
          The V1 columns are kept in FEATURE_COLS for model compatibility
          (removing them would break all trained .pkl models).
          The ML model learns they are identical and assigns one of them near-zero weight.

  FACT 5: DistanceSuit is always 1.0 for all standard distances (300-700m).
          It is retained for model compatibility; the model has learned to ignore it.

  FACT 6: TrackConditionAdj and WeightFactor are NOT in FEATURE_COLS.
          They were deliberately excluded from training because they are always 1.0
          (no track-condition data in PDFs; greyhounds' listed weights are always 0 kg).
