ROOT CAUSE — WHY ISOTONIC CALIBRATION COLLAPSES
-----------------------------------------------
The isotonic regression calibration maps raw model probability → calibrated
probability using a lookup table learned from cross-validation predictions.

Example (HEALESVILLE RF, fold 0):
  X_thresholds = [0.000, 0.009, 0.009, 0.024, 0.024, 0.748]
  Y_thresholds = [0.000, 0.000, 0.073, 0.073, 0.127, 0.127]

  → The X (input) range 0.000–0.025 is finely resolved
  → ANY input ≥ 0.024 maps to exactly 0.1267

The RF model's real-world output probabilities (8-dog races) are:
  min = 0.099, max = 0.360, mean = 0.234

Because all real-world RF outputs (0.10–0.36) are well above the last threshold
step (0.024), every single dog maps to the identical output of 0.1267.
This is not a bug in the guard code — it is a training data artefact:
the isotonic calibration was trained on fold-held-out predictions where the
proportion of winners was so low that all the step-function resolution was
consumed by the 0.00–0.02 range, leaving a flat plateau for the practical range.

This is a KNOWN scikit-learn limitation of isotonic calibration on small/sparse
win-event datasets.  The sigmoid method ('Platt scaling') does not have this
problem and should be used instead when retraining.

IMPACT IF NOT HANDLED
---------------------
If the calibration guard did NOT exist:
  - All 3 RF models would give every dog an identical score → random winner
  - Both SHEPPARTON GB and XGB would also collapse → SHEPPARTON completely broken
  - Maitland GB would be near-collapsed (0.8% spread) → very weak discrimination

  2. NEAR-collapse: score spread < 0.5% (0.005)

When detected, it falls back to the UNCALIBRATED base estimator predictions.

RECOMMENDATION 1 (RETRAIN — HIGH PRIORITY)
-------------------------------------------
Retrain all 3 tracks with `method='sigmoid'` instead of `method='isotonic'`
in the CalibratedClassifierCV constructor:

  OLD:  CalibratedClassifierCV(base_estimator, method='isotonic', cv=3)
  NEW:  CalibratedClassifierCV(base_estimator, method='sigmoid',  cv=3)

Sigmoid (Platt scaling) fits a logistic curve to map raw → calibrated probabilities.
Unlike isotonic, it cannot produce a step-function that maps a whole range to one
value — the output is always a strictly monotonic curve with full discrimination.

Alternatively, increase cv folds from 3 → 5 with more training data per track so
the isotonic lookup table covers the full practical probability range.
