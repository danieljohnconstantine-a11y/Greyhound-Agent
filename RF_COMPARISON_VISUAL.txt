┌────────────────────────────────────────────────────────────────────────────┐
│ WHY THESE IMPROVEMENTS WORK                                               │
└────────────────────────────────────────────────────────────────────────────┘

1. More Trees (n_estimators ↑)
   ╰→ Each tree votes independently
   ╰→ More diverse ensemble = more robust
   ╰→ Proven: accuracy ∝ log(n_trees)

2. Deeper Trees (max_depth ↑)
   ╰→ Can model non-linear interactions
   ╰→ Capture complex racing patterns
   ╰→ Balanced against overfitting

3. min_samples_leaf = 2
   ╰→ Prevents single-sample leaves
   ╰→ Improves generalization
   ╰→ Minimal performance cost

4. max_features = 'sqrt'
   ╰→ Samples √76 ≈ 9 features per split
   ╰→ Reduces tree correlation
   ╰→ Research-backed optimal for classification

5. class_weight = 'balanced'
   ╰→ Auto-adjusts for winner/non-winner imbalance
   ╰→ Prevents "predict no win" bias
   ╰→ Weight ≈ {0: 0.625, 1: 2.5} for 20% winners

6. Feature Importance
   ╰→ Identifies key predictive features
   ╰→ Guides future feature engineering
   ╰→ Enables continuous improvement
