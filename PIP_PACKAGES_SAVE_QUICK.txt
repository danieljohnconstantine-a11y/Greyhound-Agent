  HOW TO SAVE PIP PACKAGES PERMANENTLY
═══════════════════════════════════════════════════════════════════

QUESTION:
"is there away i can save pip install pandas numpy scikit-learn 
xgboost pdfplumber openpyxl permanently to local pc, so i dont 
have to down load each time?"

ANSWER:
✅ YES - Multiple ways!

═══════════════════════════════════════════════════════════════════
  QUICK ANSWERS
═══════════════════════════════════════════════════════════════════

Method 1: KEEP SAME VIRTUAL ENVIRONMENT ⭐ EASIEST
  • Don't delete venv/ directory
  • Packages stay installed forever
  • Just activate when needed
  
Method 2: PIP CACHE ⭐ ALREADY WORKING
  • Pip automatically caches packages
  • Second install 5-10× faster
  • No setup needed

Method 3: LOCAL REPOSITORY ⭐ ADVANCED
  • Download packages to folder
  • Install from folder anytime
  • Works completely offline

═══════════════════════════════════════════════════════════════════
  METHOD 1: KEEP SAME VENV (RECOMMENDED)
═══════════════════════════════════════════════════════════════════

THE PROBLEM (what you might be doing):
┌──────────────────────────────────────────────────────────────┐
│ cd ~/Desktop                                                 │
│ rm -rf Greyhound-Agent     ❌ DELETE everything              │
│ git clone ...              ↓  Clone again                    │
│ cd Greyhound-Agent                                           │
│ python3 -m venv venv       ↓  Create new venv                │
│ pip install [packages]     ❌ Download 179 MB again          │
└──────────────────────────────────────────────────────────────┘

THE SOLUTION (do this instead):
┌──────────────────────────────────────────────────────────────┐
│ SETUP ONCE:                                                  │
│ cd /mnt/c/Users/danie/OneDrive/Desktop/Greyhound-Agent      │
│ python3 -m venv venv                                         │
│ source venv/bin/activate                                     │
│ pip install -r requirements.txt  # Download once (10-30 min) │
│                                                              │
│ USE FOREVER:                                                 │
│ cd /mnt/c/Users/danie/OneDrive/Desktop/Greyhound-Agent      │
│ source venv/bin/activate        # Just activate! (1 second)  │
│ python train_ml_track_ensemble.py  # Works immediately!      │
│                                                              │
│ KEY: DON'T delete the Greyhound-Agent directory!            │
└──────────────────────────────────────────────────────────────┘

WHY THIS WORKS:
Virtual environment is just a folder:
  Greyhound-Agent/
  ├── venv/              ← This is just a folder!
  │   └── lib/
  │       └── site-packages/  ← YOUR PACKAGES HERE
  │           ├── pandas/     (~200 MB)
  │           ├── numpy/      (~80 MB)
  │           ├── sklearn/    (~35 MB)
  │           ├── xgboost/    (~50 MB)
  │           ├── pdfplumber/ (~2 MB)
  │           └── openpyxl/   (~1 MB)

Keep the folder = packages stay installed!

═══════════════════════════════════════════════════════════════════
  METHOD 2: PIP CACHE (AUTOMATIC)
═══════════════════════════════════════════════════════════════════

GOOD NEWS: Pip already caches packages automatically!

WHERE CACHE IS SAVED:
  Linux/WSL:  ~/.cache/pip/
  Windows:    %LocalAppData%\pip\Cache
  Mac:        ~/Library/Caches/pip/

HOW IT HELPS:

  First install (downloads):
  ┌────────────────────────────────────────────────────────────┐
  │ pip install pandas numpy scikit-learn xgboost ...          │
  │ → Downloads 179 MB from PyPI                               │
  │ → Saves to cache automatically ✅                          │
  │ → Time: 10-30 minutes                                      │
  └────────────────────────────────────────────────────────────┘

  Second install (uses cache):
  ┌────────────────────────────────────────────────────────────┐
  │ pip install pandas numpy scikit-learn xgboost ...          │
  │ → Finds in cache! ✅                                       │
  │ → Installs from cache (much faster)                        │
  │ → NO internet download needed!                             │
  │ → Time: 2-5 minutes                                        │
  └────────────────────────────────────────────────────────────┘

CHECK YOUR CACHE:
  pip cache dir       # See cache location
  pip cache info      # See cache size
  pip cache list      # List cached packages

YOUR PACKAGES ARE ALREADY BEING SAVED!

═══════════════════════════════════════════════════════════════════
  METHOD 3: LOCAL REPOSITORY (ADVANCED)
═══════════════════════════════════════════════════════════════════

CREATE PERMANENT PACKAGE STORE:

  1. Create directory for packages
  ┌────────────────────────────────────────────────────────────┐
  │ mkdir -p ~/pip-packages                                    │
  └────────────────────────────────────────────────────────────┘

  2. Download all packages once (WITH internet)
  ┌────────────────────────────────────────────────────────────┐
  │ pip download pandas numpy scikit-learn xgboost \           │
  │   pdfplumber openpyxl -d ~/pip-packages/                   │
  └────────────────────────────────────────────────────────────┘

  3. Later: Install from local (NO internet needed!)
  ┌────────────────────────────────────────────────────────────┐
  │ pip install pandas numpy scikit-learn xgboost \            │
  │   pdfplumber openpyxl --no-index \                         │
  │   --find-links ~/pip-packages/                             │
  └────────────────────────────────────────────────────────────┘

BENEFITS:
  ✅ Download once, use forever
  ✅ Works completely offline
  ✅ Reuse across multiple venvs
  ✅ Can copy to USB/external drive

  Fix: Create once, activate when needed

  ┌────────────────────────────────────────────────────────────┐
  │ python train_ml_track_ensemble.py  ❌ Wrong Python         │
  └────────────────────────────────────────────────────────────┘
  Fix: Always activate: source venv/bin/activate
