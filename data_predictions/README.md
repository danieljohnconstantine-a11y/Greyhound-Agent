# Data Predictions

Place today's race PDF form files here before running predictions.

## Usage

1. Download today's race form PDF (e.g. `ANGLG0503form.pdf`) into this folder
2. Run: `python run_track_ensemble_predictions.py`
3. Check results in `outputs/track_ensemble_predictions.xlsx`

## File Naming

PDF files should follow the standard naming convention:
- `ANGLG{DDMM}form.pdf` for Angle Park
- `BDGOG{DDMM}form.pdf` for BENDIGO
- `BRATG{DDMM}form.pdf` for BALLARAT
